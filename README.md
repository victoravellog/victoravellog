# Victor Avello

Fullstack Engineer · 12+ years · Geospatial & scientific data · Ruby/Rails · PostGIS

Currently at [UNEP-WCMC](https://www.unep-wcmc.org/) building [IBAT](https://www.ibat-alliance.org/) — the global biodiversity risk-screening tool, serving ~400 organisations and ~2,000 users across governments, banks and consultancies. I work across design, application code and infrastructure, turning global conservation datasets (WDPA, Key Biodiversity Areas, IUCN Red List) into spatial and tabular data on a Rails + PostGIS platform.

Based in the UK (originally from Chile).
